# SWYNEX Final Data Analytics Project

## About the Project
This project consolidates my Data Analytics work completed during my internship at Swynex Technologies, using the Superstore dataset to analyze sales, profit, product performance and business trends.

## Project Work
- Data preparation and analysis of Superstore data.
- Sales and profit performance analysis.
- Analysis of product categories and sub-categories.
- Regional and customer segment analysis.
- Interactive Power BI dashboard development.
- Business insights and data-driven recommendations.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Data Analysis
- Data Visualization

## Business Objective
To analyze Superstore sales data, identify profitable products and regions, understand sales trends, and support better business decisions.
